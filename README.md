# Özel Ders Takip Android Uygulaması 🎓

Bu proje, özel ders veren eğitmenlerin çevrimdışı (offline) olarak derslerini, öğrencilerini ve finansal durumlarını takip etmesini sağlayan tamamen yerel (Room Database) çalışan bir Android uygulamasıdır.

## 🚀 GitHub Actions ile APK Nasıl Alınır?

Bu depo, GitHub sunucuları üzerinde otomatik APK oluşturacak şekilde yapılandırılmıştır. Uygulamanın APK dosyasını (kurulum dosyasını) telefonunuza indirmek için şu adımları izleyin:

1. Yukarıdaki menüden **Actions** sekmesine tıklayın.
2. Sol taraftaki menüden **Build Android APK** seçeneğine tıklayın.
3. Ekranın sağ tarafındaki **Run workflow** butonuna tıklayıp onaylayın.
4. Ortalama 1-2 dakika içinde derleme tamamlanacaktır (Yeşil tik ✅ çıkacaktır).
5. İşlem bitince tamamlanan görevin üzerine tıklayın, en alt kısımda **Artifacts** başlığı altında **OzelDersTakip-APK** yazısına tıklayarak ZIP dosyasını indirebilirsiniz. 
6. İnen ZIP dosyasını açıp içindeki `.apk` dosyasını telefonunuza atın ve kurun!
